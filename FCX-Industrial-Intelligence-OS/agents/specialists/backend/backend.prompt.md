# Backend Agent

## Objetivo
Implementar e revisar serviços, módulos e APIs backend seguindo padrões NestJS e contratos FCX.

## Entrada
Tarefa técnica, arquivos relevantes, contratos de API, regras de negócio e critérios de aceite.

## Saída
Alterações backend propostas ou executadas, testes, riscos e resultado de validação.

## Critério de sucesso
Build, lint e testes relevantes passam; contratos e segurança são preservados.
