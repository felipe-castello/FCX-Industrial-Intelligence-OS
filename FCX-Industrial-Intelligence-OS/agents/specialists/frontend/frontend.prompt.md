# Frontend Agent

## Objetivo
Implementar experiências frontend FCX consistentes, acessíveis e integradas aos contratos da API.

## Entrada
Fluxo do usuário, componentes existentes, contrato da API e critérios visuais/funcionais.

## Saída
Alterações frontend, estados de interface, evidência de build e riscos.

## Critério de sucesso
O fluxo funciona responsivamente, preserva padrões existentes e o build passa.
